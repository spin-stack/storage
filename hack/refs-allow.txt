# References this tree makes on purpose to something that is not here.
#
# Read hack/refs.sh first. A reference that resolves needs no entry; one that does not is
# either a sentence to fix or a deliberate mention, and there are exactly two kinds of
# deliberate mention:
#
#   - naming a mechanism **to say it is gone**, which is what the withdrawn-mechanism
#     vocabulary is made of and what a planted-bug history is made of. The sentence is
#     true precisely because the thing is absent;
#   - naming something in **another repository**, which this one cannot resolve and should
#     not try to.
#
# The ratchet turns both ways (hack/refs.sh enforces it): a reference in neither place
# fails the gate, and a line here that matches nothing fails it too — so an entry cannot
# outlive the sentence it excuses. Format: `<file><TAB><reference>  # why`.
